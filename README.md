# PRACTICE-SVG-Embedding-Accessibility-Starter

##Viewbox Explanation
The SVG uses viewbox="0 0 600 300" which means its coordinate system starts at (0,0) and is 600 units wide and 300 units tall. This allows the graphic to scale without distorting its proportions.

##Accessibility Testing
I inspected the inline SVG using Chrome Developer tool. The accessibility tree identified it as an image and displayed its accessible name and description.
